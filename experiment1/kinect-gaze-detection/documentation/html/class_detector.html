Detailed Description

The Detector class.

This is the main class for detection and tracking of facial attributes.

Contributors:

  • Ana Christina Almada Campos (anach.nosp@m.rist.nosp@m.inaac.nosp@m.@gma.nosp@m.il.co.nosp@m.m) This class is responsible for the detection and tracking of face attributes, the eyes and mouth. The methods used here are implemented in detection.cpp and detection_kalmanfilter.cpp.

Parameters
frame_rate- A double with the frame rate of the camera.
face_file- Path to the face cascade file.

eyes_file- Path to the eyes cascade file.
mouth_file- Path to the mouth cascade file.
kCov- An array with the values for reinitialization of posteriori error estimate covariance matrices.
flag_show- An int to indicates if results should be displayed.

The constructor of the object loads the cascade files, sets the sampling interval, according to the given frame rate, sets the values for reinitization of KF filters and the flag to indicate if results should be displayed.

◆ kf_lefteye

KalmanFilter Detector::kf_lefteye {KalmanFilter(4,2,0)}

Kalman filters for each of the face features. States are [x vx y vy], where: x = x coordinate of the center of the rectangle for eyes and mouth x coordinate for the pupil centers vx = velocity of the x coordinate of the center of the rectangle for eyes and mouth velocity of the x coordinate for the pupil centers y = y coordinate of the center of the rectangle for eyes and mouth y coordinate for the pupil centers vy = velocity of the y coordinate of the center of the rectangle for eyes and mouth velocity of the y coordinate for the pupil centers

Four dynamic parameters, two measurement parameters and zero control parameters.
